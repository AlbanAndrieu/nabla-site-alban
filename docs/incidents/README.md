## Contenu attendu

Un incident conservé doit contenir le périmètre, les symptômes/preuves, la cause
confirmée ou le niveau d'incertitude, la mitigation, les commandes utiles, le
rollback et les actions restantes. Les chronologies de commits ou détails sans
valeur diagnostique peuvent rester dans GitHub au lieu d'être dupliqués ici.
